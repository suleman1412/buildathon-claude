AI Research Paper Validator / run history

Claimed vs. reproduced metrics, per paper
How it works

For each paper, an LLM reads the PDF to find its code repo and headline claim, clones the repo, then writes a shell command to reproduce the result. If that command fails or its output doesn't match, the same LLM reads the error and patches its own attempt — up to five times — before the reproduced number is checked against the paper's claim.

Reads dashboard/data/runs.json, written by validate.py after each run.
